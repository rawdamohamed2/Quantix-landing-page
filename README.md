Quantix SaaS Landing Page

A modern and responsive SaaS landing page built with HTML, CSS, and Vanilla JavaScript.

This project was created as a practical revision and challenge to strengthen my core frontend skills without using any frontend frameworks.

🚀 Live Demo

"View Live Demo" (https://rawdamohamed2.github.io/Quantix-landing-page/)

📌 About The Project

Quantix is a modern SaaS landing page featuring a clean UI, responsive layouts, interactive sections, animations, and dynamic elements.

The project focuses on practicing and improving fundamental frontend development skills, especially:

- Semantic HTML structure
- Modern CSS layouts and styling
- Responsive design
- DOM manipulation
- JavaScript events and interactions
- CSS animations and transitions

✨ Features

- Responsive navigation bar
- Mobile-friendly menu
- Hero section with modern UI
- Animated statistics
- Interactive feature tabs
- Monthly / yearly pricing toggle
- Pricing cards
- FAQ section
- Scroll animations
- Hover effects and smooth transitions
- Fully responsive layout for different screen sizes
